MdReader

Renders every Markdown file you open in Chrome with the Paper, Studio or Sections theme, and lets you edit and save it back.

Local files

For file://…/something.md to render, Chrome needs one switch flipped:

  1. Open chrome://extensions
  2. Click Details on MdReader
  3. Turn on Allow access to file URLs

Saving from a file:// page asks you to pick the same file once (Chrome's permission model); after that ⌘S writes in place. The Open in app button hands the file to the MdReader desktop app instead.
